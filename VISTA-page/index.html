01 Experience becomes executable capability

Improve the harness.
Keep the models fixed.

A robot’s harness organizes its instructions, skills, memory, and decision logic. VISTA makes this executable layer the object of improvement, combining learning-based policies, perception, motion planning, and feedback control.

A meta-agent starts with a harness version and its execution evidence. It can investigate the environment, develop new skills, and test candidate changes. Useful discoveries are written into the harness and validated through autonomous execution.

Versions and their supporting evidence remain available for later development. The result is a process in which embodied experience can accumulate as reusable code and procedural knowledge.

02 The development loop

A meta-agent that can
run its own experiments.

Active exploration gives the meta-agent control over how it obtains new evidence: what to observe, which operations to try, and what to investigate next.

Start from a version and its evidence

Connect an outcome to the decisions that produced it.

Inspect the current harness together with observations, tool calls, robot actions, and task outcomes. Use this evidence to identify a behavior to improve and a hypothesis worth testing.

Exploration informs development; autonomous evaluation checks the result. Submitted harnesses are frozen and evaluated without meta-agent intervention. Selection determines which version is retained.
